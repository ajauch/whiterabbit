# WhiteRabbit Brand Assets

**Brand color:** `#103459` (navy), sampled from the original raster logo.

## Files

| File | Use |
|------|-----|
| `hare.svg` | Mark alone, `fill="currentColor"` — recolors via CSS |
| `hare-navy.svg` | Mark with hardcoded navy fill |
| `hare-square.svg` | Mark centered in 1:1 viewBox with 10% padding — avatars, app icons |
| `wordmark.svg` | Hare + WHITERABBIT text, `currentColor` — README header, docs |
| `favicon.svg` | Square mark with navy fill — browser tabs |
| `favicon-{16,32,48,180}.png` | Raster favicons; 180px is the Apple touch icon |
| `social-preview.png` | 1280x640, wordmark centered on white — GitHub/social embeds |

## Source

The SVGs are hand-simplified vector traces of the original raster logo
(`Images/WhiteRabbit Logo.jpg`), not auto-generated exports. The hare path
uses 60 nodes total (51 body + 9 front paw) with straight line segments
matching the faceted style of the original.

Do not re-trace from the raster — edit the SVG paths directly if the mark
needs adjustment.

The wordmark text (Arial Black, converted to paths) has no font dependency.
